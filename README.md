# PDF to Audio Converter

PDF to Audio Converter is a small desktop app built with Python and Tkinter. It extracts the text from a PDF, saves it as a text file, and converts it to speech as an MP3 and a WAV file.

> **Project note:** Speech is generated with Google's text-to-speech service through the `gTTS` library, so an internet connection is required. The app reads text-based PDFs only; scanned PDFs (images of pages) have no text to extract.

## Features

- Simple graphical interface for choosing a PDF file.
- Text preview for a chosen page range, with an option to save it as a `.txt` file.
- Full-document conversion to an MP3 audio file.
- Automatic WAV copy of the MP3 using ffmpeg.
- Slow speed option for clearer narration.
- Conversion runs in a background thread so the window stays responsive.

## Tech Stack

- **Language:** Python 3
- **GUI:** Tkinter
- **PDF text extraction:** PyPDF2
- **Text-to-speech:** gTTS (Google Text-to-Speech)
- **Audio conversion:** ffmpeg

## Requirements

- Python 3.8 or later
- Tkinter (included with Python on Windows and macOS; on Debian/Ubuntu install it with `sudo apt install python3-tk`)
- [ffmpeg](https://ffmpeg.org/download.html) installed and available on your system `PATH`
- An internet connection

## Installation

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
pip install PyPDF2 gTTS
```

Check that ffmpeg is installed:

```bash
ffmpeg -version
```

## Usage

```bash
python main.py
```

1. Click **Select PDF Files** and choose a PDF.
2. Click the file name in the list to select it.
3. *(Optional)* Click **Preview Text**, enter a start and end page, and choose where to save the text file.
4. Tick **Slow Speed** if you want slower narration.
5. Click **Convert to Audio**, then choose where to save the text file and the MP3.
6. The WAV file is created next to the MP3 with the same name.

## Output Files

| File | Description |
| --- | --- |
| `.txt` | Extracted text of the PDF |
| `.mp3` | Spoken audio generated by gTTS |
| `.wav` | WAV version of the MP3, created with ffmpeg |

## Known Limitations

- Only one PDF is converted at a time. You can load several files into the list, but only the selected one is used.
- The language is fixed to English.
- Scanned PDFs are not supported because the app does not use OCR.
- Characters outside the basic Unicode range (such as emoji) are removed from the text.
- Very large PDFs may be slow or fail, since the whole text is sent to the online service in one request.
- Audio conversion always converts the full document. Page ranges only apply to the text preview.
- There are no automated tests.
